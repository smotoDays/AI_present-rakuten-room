# 副業_楽天ROOM 自動化AI社員チーム

Claude Code 1人が5役を兼任して、楽天ROOMの運用（リサーチ→ライティング→投稿→分析）を回すチーム。

## 組織図
- 社長＝あなた（オーナー。最初の設定を一度するだけ）
- 司令塔＝スキル `rakuten-room`（各係に「次はこれ」と順番に指示）
- ①自己紹介文作成係 … `rakuten-profile`
- ②商品リサーチ係 … `rakuten-research`
- ③ライティング係 … `rakuten-writer`
- ④投稿オペレーター … `rakuten-poster`（Chromeで実投稿。デフォルト承認モード）
- ⑤スケジュール管理係 … `rakuten-scheduler`（朝・昼・夜の段取り＋KPI）

## 使い方
Claude Code で次のように言うだけ：
- 立ち上げ：「楽天ROOMを立ち上げて」→ プロフィール作成から
- 日次運用：「楽天ROOMの朝（/昼/夜）を回して」→ 1サイクル実行
- 振り返り：「楽天ROOMの週次振り返り」→ KPI診断

スキル `/rakuten-room` が司令塔として5役を順番に起動します。

## フォルダ構成
- `プロフィール/` … 自己紹介文（立ち上げ時に作成）
- `商品リサーチ/` … 日々の商品候補メモ
- `投稿/` … 投稿案・投稿ログ
- `投稿キュー/` … 未投稿の繰り越し
- `分析/` … 日次段取り・週次KPI
- `ナレッジ/` … 勝ちパターン（運用しながら更新）
- `templates/` … 投稿・リサーチの雛形

## 運用ルール（重要）
- **投稿は1サイクル3〜5件・人間らしい間隔**。連投・全自動ループは規約リスク（アカBAN）。
- 投稿オペレーターのデフォルトは**承認モード**（1件ごとにオーナーがOKしてから投稿）。フル自動はリスク承知で明示した時だけ。
- ログインはオーナー本人。ID/パスワードはAIが扱わない。
- 法令（景表法・薬機法・著作権）と楽天規約を守る。数値は捏造しない。

## アカウント未作成の場合
楽天会員登録（SMS認証・個人情報入力＝本人）→ 楽天ROOMでニックネーム設定・規約同意。
Chromeで画面を案内し、認証コード等はオーナーが入力する。
