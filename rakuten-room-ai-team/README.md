# 楽天ROOM 自動化AI社員チーム（Claude Code プラグイン）

楽天ROOMのアフィリ運用を、**Claude Code の「AI社員チーム」**で回す仕組み一式です。
司令塔スキル1つ ＋ AI社員5人 ＋ 作業フォルダ雛形が入っています。

> 📦 このリポジトリには配布者個人の情報（氏名・メール・楽天アカウント・実投稿データ）は**一切含まれていません**。
> 使う人が、自分のアカウントとPC環境でゼロから立ち上げる前提です。

---

## チーム構成（組織図）

| 役割 | エージェント | 仕事 |
|---|---|---|
| 司令塔 | スキル `rakuten-room` | 5役を正しい順番で動かす |
| ①自己紹介文作成係 | `rakuten-profile` | プロフィール自己紹介を作る（立ち上げ1回） |
| ②商品リサーチ係 | `rakuten-research` | 売れそうな商品を探す。売り切れ・高すぎは外す |
| ③ライティング係 | `rakuten-writer` | 紹介文とハッシュタグを書く |
| ④投稿オペレーター | `rakuten-poster` | Chromeで実際に投稿（デフォルト承認モード） |
| ⑤スケジュール管理係 | `rakuten-scheduler` | 朝・昼・夜の段取り＋KPI |

---

## 使うのに必要なもの
1. **Claude Code**
2. **Claude for Chrome 拡張**（④投稿オペレーターが楽天ROOMを操作する道具）
3. **楽天会員＋楽天ROOMのアカウント**（自分のもの。ログインは本人）

---

## インストール方法

### 方法A：プラグインとして入れる（おすすめ）
Claude Code で次を実行：
```
/plugin marketplace add <あなたのGitHubユーザー名>/rakuten-room-ai-team
/plugin install rakuten-room-ai-team@rakuten-room-ai-team
```
これで司令塔スキルとAI社員5人が自動で読み込まれます。
そのあと、リポジトリ内の `作業フォルダ雛形/副業_楽天ROOMチーム/` を、自分の作業プロジェクト直下にコピーしてください。

### 方法B：手動で入れる
```bash
# 司令塔スキル → ユーザー共通の skills へ
cp -r skills/rakuten-room ~/.claude/skills/

# AI社員5人 → 作業プロジェクトの .claude/agents へ
cp -r agents/* <あなたのプロジェクト>/.claude/agents/

# 作業フォルダ雛形 → 作業プロジェクト直下へ
cp -r 作業フォルダ雛形/副業_楽天ROOMチーム <あなたのプロジェクト>/
```

## 使い方
Claude Code で話しかけるだけ：
- 立ち上げ：「**楽天ROOMを立ち上げて**」→ ①がプロフィール案を作る
- 日次運用：「**楽天ROOMの朝（/昼/夜）を回して**」→ ②③④が1サイクル回す
- 振り返り：「**楽天ROOMの週次振り返り**」→ ⑤がKPI診断

---

## 安全運用のルール（必ず守る）
- 投稿は **1サイクル3〜5件・人間らしい間隔**。連投・全自動ループは楽天規約違反でアカBANリスク。
- ④投稿オペレーターのデフォルトは **承認モード**（1件ごとに本人がOKしてから投稿）。フル自動はリスクを承知した上で明示したときだけ。
- ログインID/パスワードはAIに渡さない・保存しない。
- 景表法・薬機法・著作権・楽天の各規約を守る。誇大表現や他人のレビュー丸写しはしない。数値は捏造しない。

## よくある質問
**Q. これを入れればボタン1つで全自動になる？**
A. なりません。「ノウハウと指揮系統の仕組み」一式です。Claude Code・Chrome拡張・自分の楽天アカウントが必要で、投稿は本人が承認します。

**Q. 自動投稿で楽天に怒られない？**
A. 楽天ROOMはbot自動投稿を制限しています。だから承認モード・件数/間隔ガードを標準にしています。フル自動は自己責任。

**Q. カスタマイズしたい**
A. ジャンルやトーンは `rakuten-profile`、勝ちパターンは `作業フォルダ雛形/副業_楽天ROOMチーム/ナレッジ/勝ちパターン_楽天ROOM.md` を書き換えれば、チーム全員の判断基準が変わります。
